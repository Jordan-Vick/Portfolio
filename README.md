# Jordan Vick · Engineering Portfolio

Live site: https://jordankylevick-sudo.github.io/Portfolio_JV/

Static site (HTML/CSS/JS, no build step). Projects:

- **320-Channel Control System for an Optical Phased Array** (NRC Nanophotonics, 2024): `projects/opa-controller.html`, with the interactive three.js model in `opa-3d/`

Company logos: drop square PNGs named `skyworks.png`, `nrc.png`, `wize.png` and `queens.png` into `assets/img/logos/` to replace the auto-fetched favicons.

To add a project: copy one of the pages in `projects/`, add its images to `assets/img/`, and add a card to `index.html`.
